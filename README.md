\# Production-Style DevOps CI/CD Pipeline



A portfolio-level CI/CD project demonstrating automated testing, Docker containerization, Docker Compose, GitHub Actions, Docker Hub, and Kubernetes deployment.



\## Architecture



Developer → GitHub → GitHub Actions → Tests → Docker Build → Security Scan → Docker Hub → Kubernetes/Minikube



\## Application



The project uses a Node.js and Express application with:



\- `/` - Application information

\- `/health` - Health check

\- `/version` - Version and build information



\## Technologies



\- Node.js

\- Express

\- Jest

\- Supertest

\- Docker

\- Docker Compose

\- GitHub Actions

\- Docker Hub

\- Kubernetes

\- Minikube

\- Git \& GitHub
